Лабораторная работа №1: калькулятор и конвертер



Цель работы:
Разработать CLI-приложение на Python, которое позволяет выполнять арифметические вычисления и конвертировать
значения между различными единицами измерения.

Программа запускается из командной строки с помощью команды python -m toolkit.



Описание проекта:

Программа состоит из двух основных частей:
    Калькулятор - вычисляет выражения с операциями сложения, вычитания, умножения и деления.
    Конвертер - переводит значения между единицами длины, массы и температуры.

Для проверки корректности введённых данных используются отдельные функции валидации.
Проект также содержит автоматические тесты для вычислительного ядра и командного интерфейса.

Запуск программы:

Калькулятор запускается командой: 
python -m toolkit calc "арифметическое_выражение"

Например:
python -m toolkit calc "2+3*4"

Результат:
14.0

Для получения справки используется команда:
python -m toolkit --help



Калькулятор:

Калькулятор поддерживает следующие операции:
    + - сложение;
    - - вычитание;
    * - умножение;
    / - деление.

Поддерживаются целые и вещественные числа, а также унарные знаки + и -.

При вычислении учитывается стандартный приоритет арифметических операций: умножение и деление
выполняются раньше сложения и вычитания.

Некорректные выражения, например выражения с отсутствующим операндом или делением на ноль, отклоняются программой.



Конвертер:

Конвертер поддерживает три группы единиц измерения.


Длина:

Поддерживаются:
    mm - миллиметры;
    cm - сантиметры;
    m - метры;
    km - километры.

Пример:
python -m toolkit convert 100 --from cm --to m

Результат:
1.0


Масса:

Поддерживаются:
    g - граммы;
    kg - килограммы.

Пример:
python -m toolkit convert 5 --from kg --to g

Результат:
5000.0


Температура:

Поддерживаются:
    c - градусы Цельсия;
    k - Кельвины;
    f - градусы Фаренгейта.

Пример:
python -m toolkit convert 100 --from c --to f

Результат:
212.0


Названия единиц измерения можно вводить в разных регистрах.

Для физических величин, для которых отрицательные значения невозможны, выполняется дополнительная проверка
корректности введённого значения. Для температуры также проверяется невозможность значения ниже абсолютного нуля.



Обработка ошибок:

Программа проверяет корректность введённых данных.

Ошибки возникают, например, если:
    введено некорректное арифметическое выражение;
    используется неизвестный оператор;
    выполняется деление на ноль;
    введено некорректное число;
    указаны несовместимые единицы измерения;
    указана неизвестная единица измерения;
    введена температура ниже абсолютного нуля.



Тестирование:

Для автоматической проверки программы используется библиотека pytest.

Запуск всех тестов: 
pytest -v

Тесты проверяют:
    корректные вычисления калькулятора;
    учёт приоритета операций;
    некорректные арифметические выражения;
    деление на ноль;
    различные варианты конвертации;
    граничные значения температур;
    некорректные значения и единицы измерения;
    работу командного интерфейса;
    корректную обработку ошибок при запуске через CLI.

Для проверки качества кода используется ruff:
ruff check .

Успешное выполнение тестов и проверки ruff означает, что текущая версия проекта проходит
предусмотренные автоматические проверки.
